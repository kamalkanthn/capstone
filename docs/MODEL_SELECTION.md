# Model selection

Status: the isolated-sign prototype is trained. A separate ISLiM continuous pose-to-English branch has been trained experimentally. The best checkpoint is from 600 GloSL clips; resumed training with 1,500 clips did not improve validation. On 200 held-out clips it scored BLEU-4 0.15, ROUGE-L 6.26, and WER 167.87%, with repetitive generic phrases. It is not suitable for live use. Candidate papers use different datasets and tasks, so reported scores are not a common ranking.

| Candidate | Task fit | Benefits | Constraints / evidence limits | Decision |
|---|---|---|---|---|
| Landmark/frame classifier (non-temporal) | Sanity-check baseline for isolated signs | Cheap, simple diagnostic for whether preprocessing and labels work | Cannot satisfy dynamic-recognition objective by itself | Use only as a reference baseline, not final system. |
| Landmark temporal model (GRU/LSTM) | Isolated dynamic clips | Lightweight and interpretable starting comparison; preserves time order | Depends on quality of pose/hand extraction; landmarks can lose appearance and non-manual cues | **Primary first implementation candidate**, conditional on data availability. |
| CNN + LSTM/GRU on RGB | Isolated dynamic clips | Retains visual appearance with temporal modeling | More compute; overfit risk on small data; latency must be measured | Credible alternative if permitted RGB data and hardware support it. |
| 3D CNN / video encoder | Clip-level spatial-temporal recognition | Learns motion from RGB | Higher memory/compute; dataset and pretraining provenance matter | Defer until a valid baseline exists. |
| SSTAN stacked spatial-temporal Transformer | Skeleton/landmark dynamic sign/fingerspelling recognition | Paper describes sequential spatial and temporal attention | Reported WLASL/JSL/KSL results do not establish ISL performance; paper reports long schedules and 18.46 GMac default profile; no implementation/data in workspace | Research comparison candidate after baseline, not assumed winner. |
| Graph spatial-temporal model | Landmark sequences | Encodes skeleton structure directly | Requires reliable landmark topology; may miss RGB/facial/manual detail | Alternative for controlled ablation if dataset supports it. |
| SignFlow (3DResNet RGB encoder + pose Transformer + CTC) | Continuous ISL gloss recognition | Closest match to real-time continuous ISL; paper reports WER 19 and domain-specific pretraining | Predicts gloss/word sequences, not fluent English; its UMANG-eRaktkosh continuous corpus is described as not publicly available and no reproducible public implementation/checkpoint was verified | Keep as architecture/evaluation reference; cannot reproduce from currently available project data. |
| ISLiM (94-point pose encoder: temporal Conv1D + Transformer; T5-small decoder) | Continuous gloss-free ISL-to-English translation | Directly maps pose sequences to English; public Apache-2.0 code and pretrained-model link; paper reports ~384 ms CPU inference | iSign access and pre-extracted keypoints are required; reported BLEU-4 is 5.85, so it is a starting baseline, not evidence of high translation quality | **Selected continuous translation baseline**, pending dataset access and local checkpoint integration. |
| Distillation/quantization/ONNX | Deployment optimization | Potentially reduces latency/model footprint | Can reduce accuracy; must be measured on target hardware | Defer until profiling identifies a bottleneck. |

## Initial selection

Keep the existing RGB MobileNetV3 + BiGRU for isolated-word windows. Train ISLiM as the separate continuous pose-to-English branch: its temporal Conv1D/Transformer encoder plus T5-small decoder is a reproducible direct translation baseline, and its public code supports multimodal contrastive training. The GloSL ISL dataset is available locally and uses official source-video-disjoint splits. The best checkpoint was trained on 600 clips; resumed training over a 1,500-clip subset did not improve validation. Its 200-clip held-out test produced BLEU-4 0.15, ROUGE-L 6.26, and WER 167.87%. It repeats generic phrases and must not be routed to users. Continue with the larger/full dataset and debug pose/text alignment or training before integration. SignFlow remains the closest real-time architecture match (RGB + pose + CTC, paper WER 19), but the paper's UMANG-eRaktkosh corpus and training implementation/checkpoint were not verified as reproducible here.

## References and verification notes

- Hirooka et al., “Stack Transformer-Based Spatial-Temporal Attention Model for Dynamic Sign Language and Fingerspelling Recognition,” IEEE Open Journal of the Computer Society, 2026, DOI: [10.1109/OJCS.2026.3682330](https://doi.org/10.1109/OJCS.2026.3682330). Its abstract describes spatial MHA followed by temporal MHA; reported datasets include WLASL, JSL, KSL. This is not an ISL result.
- Geetha et al., “Toward Real-Time Recognition of Continuous Indian Sign Language: A Multi-Modal Approach Using RGB and Pose,” IEEE Access 13 (2025), DOI: [10.1109/ACCESS.2025.3554618](https://doi.org/10.1109/ACCESS.2025.3554618). SignFlow uses RGB CNN features, pose Transformer features and CTC; reports WER 19. Its paper says the UMANG-eRaktkosh continuous corpus was newly collected because no public CSLR benchmark existed at the time. This is the best task match in the survey, but not currently reproducible in our workspace.
- Ahmed & Mishra, “ISLiM: A Compact End-to-End Sign Language Translation Framework,” WSLP 2026: [paper](https://aclanthology.org/2026.wslp-1.3/), [Apache-2.0 implementation](https://github.com/ahmedshoaib/ISLiM). The repository describes a 94-landmark temporal Conv1D/Transformer encoder and T5-small decoder; its reported iSign test BLEU-4 is 5.85. It warns that CE-only training on small subsets causes mode collapse and recommends CE, pose/text contrastive, semantic, and entropy losses. This project uses CE, contrastive, and entropy losses in the small pilot; the poor result reinforces that the pilot is not ready for deployment.
- Kumari & Anand, “Isolated Video-Based Sign Language Recognition Using a Hybrid CNN-LSTM Framework Based on Attention Mechanism,” Electronics 13(7), 1229 (2024), DOI: [10.3390/electronics13071229](https://doi.org/10.3390/electronics13071229). The deck reports its WLASL-100 evaluation; WLASL is ASL and is not evidence of ISL accuracy.
