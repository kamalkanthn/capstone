ABOUT THIS DEMO

Honest progress, visible.

This local website is the first interface shell for the bidirectional ISL capstone. It supports local media preview and browser text-to-speech. Video recognition, speech transcription, machine translation, and ISL sign generation need their respective models and reviewed assets before they can produce results.
